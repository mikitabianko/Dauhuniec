# Official documentation sources

Catalog researched on 2026-10-19. Dauhuniec opens original publisher documents without rewriting or summarizing their contents. PDFs are downloaded on demand, not redistributed inside the extension. The publisher may update a document at the same URL; compare the document revision with the firmware package used in your project.

Newer HAL generations and families without a catalog PDF use the official STM32Cube firmware-package documentation page. WBA, WB0, WL3 and H7RS are distinct families; Dauhuniec does not substitute a neighboring family manual.

## RTOS publishers

- [FreeRTOS · Full documentation and API reference](https://www.freertos.org/Documentation/00-Overview) — FreeRTOS; online reference.
- [CMSIS-RTOS2 · Full API reference](https://arm-software.github.io/CMSIS_6/main/RTOS2/group__CMSIS__RTOS.html) — Arm; online reference.
- [CMSIS-RTOS v1 · Full API reference (legacy)](https://arm-software.github.io/CMSIS_5/latest/RTOS/html/index.html) — Arm; online reference.
- [STM32Cube with RTOS · UM1722 (integration guide)](https://www.st.com/resource/en/user_manual/um1722-developing-applications-on-stm32cube-with-rtos-stmicroelectronics.pdf) — STMicroelectronics; PDF available for offline download.
- [FreeRTOS · Reference manual V10.0.0 (legacy PDF)](https://www.freertos.org/media/2018/FreeRTOS_Reference_Manual_V10.0.0.pdf) — FreeRTOS; PDF available for offline download.

The FreeRTOS V10.0.0 PDF is a legacy reference for that version, not the current kernel API. UM1722 describes STM32Cube integration and is not a replacement for the full FreeRTOS or Arm API reference. Online HTML references are not mirrored for offline use.
